# SupeRR Selector Round 1 — Streamlit dashboard

## Local setup
1. Install Python 3.10+.
2. Place `app.py`, `requirements.txt`, `batting_full_rankings.csv`, `bowling_full_rankings.csv` together.
3. In that folder, run `pip install -r requirements.txt`.
4. Run `streamlit run app.py`.

## Public dashboard
1. Create a GitHub repository and upload the four files.
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Select your repository, branch `main`, main file `app.py`.
4. Deploy and copy the generated `*.streamlit.app` link.

This dashboard uses precomputed rankings from the provided analysis. The official Round 1 submission requires rankings and methodology report; a dashboard is optional.
